How to run:
1. Install Node.js (LTS) from https://nodejs.org
2. Open a terminal in this folder
3. npm install
4. npm run dev
5. Open the link shown (usually http://localhost:5173)

To use your own photo: put it in the "public" folder (e.g. me.jpg)
and change imageUrl="/avatar.svg" to imageUrl="/me.jpg" in src/App.jsx.
